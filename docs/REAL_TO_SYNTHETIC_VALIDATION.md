# Validation réel / synthétique

## Principe

Le réalisme visuel ne prouve pas que les données synthétiques améliorent les modèles.

## Protocole

- conserver un lot réel français hors entraînement ;
- entraîner avec et sans données synthétiques ;
- comparer par domaine ;
- analyser les erreurs ;
- mesurer la calibration ;
- surveiller les artefacts de rendu ;
- documenter les régressions.

## Domaines

- sol ;
- UAV ;
- montagne ;
- rural ;
- agricole ;
- jour ;
- nuit ;
- proche ;
- lointain ;
- fumée diffuse ;
- occultation ;
- négatifs difficiles.

## Décision

Une famille synthétique est promue seulement si elle apporte un bénéfice documenté sans dégrader les domaines critiques.

Une amélioration sur le synthétique seul n’est pas une preuve.
